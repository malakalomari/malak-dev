How I work

  1. Measure first

    I check bundles, scores and contrast before and after a change, so results are real.

  2. Ship in small steps

    Big changes go out page by page, so the product keeps moving while it improves.

  3. Automate the rules

    Build checks catch missing translations, contrast failures and lint issues before release.

  4. Work across the stack

    Typed GraphQL contracts and close work with backend engineers and designers.
