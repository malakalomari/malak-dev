Case study

Marketplace Web App

The customer website of a large Saudi real-estate marketplace: search, listing pages, maps and checkout. I was its top contributor for five years, focused on speed, SEO and payments.

  • Next.js
  • React
  • GraphQL
  • Apollo
  • Google Maps
Role
Frontend Engineer → Senior · main contributor
Timeline
2021 – 2026
Platform
Web · Next.js · Arabic (RTL) + English

Context & role

What I owned.

People use the site to search for homes, browse them on a map and pay for listings, packages and rent. I built and maintained most of these journeys, working with backend engineers and designers.

What I owned

  • Search, filters and listing pages, rendered on the server for SEO
  • The map view with listing pins
  • Core Web Vitals: layout shift, image loading and fonts
  • Checkout: new and saved cards, wallet, promo codes and Apple Pay
  • Rent-now-pay-later landing pages and checkout

Approach

How I made the core pages fast and findable.

  • Built for search engines

    Server-rendered listing and region pages, with filters mapped to indexable URLs.

  • Speed first

    Fixed layout shift, lazy-loaded listing images, preloaded fonts and refactored search, listing detail and map to ship less JavaScript.

  • One checkout

    A single payment flow for every method, with purchase tracking on each one.

Results

Headline outcomes.

  • ~35%Smaller JavaScript bundle
  • 4Payment methods in one checkout
  • 5 yrsAs top contributor
