Case study

Admin Console

An internal admin platform with 50+ screens, rebuilt from Material UI onto a design system I rolled out across the whole app, Arabic-first.

  • React 19
  • TypeScript
  • Vite
  • GraphQL
  • Tailwind
Role
Senior Frontend Engineer · main contributor
Platform
Web · Arabic (RTL) + English

Context & role

What I owned.

Operations teams use this console every day to moderate listings, manage users and payments, run campaigns and follow the market. I'm the main frontend contributor: architecture, most screens, the design system and the performance work, including the stats dashboards built with Chart.js on GraphQL data.

Approach

How 50+ screens became one product.

  • Design system

    Theme tokens for light and dark mode and shared page patterns, replacing Material UI across every page.

  • Incremental rollout

    Migrated page by page in small batches while features kept shipping.

  • Arabic-first

    Right-to-left by default, with English second.

Results

Compared with the Material UI app it replaced.

  • ~60%Less JavaScript on first load
  • 50+Screens on one design system
  • AAWCAG contrast in light and dark themes
  • 2Languages, Arabic-first
