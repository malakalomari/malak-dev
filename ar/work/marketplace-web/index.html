السياق والدور

ما الذي توليته.

يستخدم الناس الموقع للبحث عن العقارات وتصفحها على الخريطة والدفع مقابل الإعلانات والباقات والإيجار. بنيت معظم هذه المسارات وطوّرتها بالتعاون مع مهندسي الخلفية والمصممين.

ما توليته

  • البحث والفلاتر وصفحات العقارات، مع العرض من الخادم لمحركات البحث
  • عرض الخريطة مع دبابيس العقارات
  • Core Web Vitals: ثبات التخطيط وتحميل الصور والخطوط
  • الدفع: البطاقات الجديدة والمحفوظة والمحفظة وأكواد الخصم وApple Pay
  • صفحات ومسار الدفع لخدمة استأجر الآن وادفع لاحقًا

المنهجية

كيف جعلت الصفحات الأساسية سريعة وسهلة الظهور.

  • مبني لمحركات البحث

    صفحات العقارات والمناطق تُعرض من الخادم، والفلاتر مرتبطة بروابط قابلة للفهرسة.

  • السرعة أولًا

    إصلاح انزياح التخطيط، والتحميل الكسول للصور، والتحميل المسبق للخطوط، وإعادة بناء البحث وصفحة العقار والخريطة لتحمل JavaScript أقل.

  • مسار دفع واحد

    مسار دفع واحد لكل الطرق، مع تتبع الشراء في كل منها.
